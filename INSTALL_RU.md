# Инструкция по установке, обновлению и удалению

## Назначение

Эта инструкция предназначена для установки программы `Мониторинг сети` на компьютеры пользователей. Пользователь получает один готовый EXE-файл установщика и не получает исходный код проекта.

## Какой файл выбрать

Готовые установщики находятся в папке:

```text
artifacts
```

Используйте один из файлов:

```text
NetworkMonitorSetup-x64.exe
NetworkMonitorSetup-x86.exe
```

`NetworkMonitorSetup-x64.exe` подходит для большинства современных компьютеров с 64-битной Windows.

`NetworkMonitorSetup-x86.exe` используйте только для старых 32-битных систем.

Важно: не переименовывайте файл так, чтобы из имени исчезло слово `Setup`, `Install` или `Installer`. По этому слову программа понимает, что её нужно запустить в режиме установки.

## Установка

1. Скопируйте нужный установщик на компьютер пользователя.
2. Запустите установщик двойным щелчком.
3. Подтвердите запрос Windows на права администратора.
4. Дождитесь сообщения `Установка завершена`.
5. Если программа предложит запуск сразу после установки, выберите нужный вариант.

После установки основной файл программы будет находиться здесь:

```text
C:\Program Files\NetworkMonitor\NetworkMonitor.exe
```

Также будет создан ярлык в меню Пуск:

```text
Мониторинг сети
```

## Что создаётся при установке

Установщик выполняет следующие действия:

- копирует программу в `C:\Program Files\NetworkMonitor`;
- создаёт ярлык в общем меню Пуск;
- создаёт запись удаления в Windows;
- не размещает исходный код на компьютере пользователя.

## Где хранятся пользовательские данные

Пользовательские данные хранятся отдельно от установленной программы:

```text
%AppData%\NetworkMonitor
```

Основные файлы:

```text
manual_ips.json
server_ips.json
service_endpoints.json
default_services.json
```

Назначение файлов:

- `manual_ips.json` - IP-адреса, добавленные вручную;
- `server_ips.json` - известные серверные IP для автоматической проверки каждые 10 минут;
- `service_endpoints.json` - рабочий список сервисов во вкладке `Сервисы`;
- `default_services.json` - дефолтный список сервисов, созданный при первом запуске.

При обновлении программы эти файлы не удаляются.

## Обновление

Для обновления установите новую версию поверх старой:

1. Закройте программу `Мониторинг сети`, если она запущена.
2. Скопируйте новый установщик на компьютер пользователя.
3. Запустите новый `NetworkMonitorSetup-x64.exe` или `NetworkMonitorSetup-x86.exe`.
4. Подтвердите права администратора.
5. Дождитесь завершения установки.

Старый файл программы будет заменён новым.

Пользовательские данные в `%AppData%\NetworkMonitor` сохраняются.

## Удаление через Windows

Рекомендуемый способ удаления:

1. Откройте `Параметры Windows`.
2. Перейдите в `Приложения`.
3. Найдите `Мониторинг сети`.
4. Нажмите `Удалить`.
5. Подтвердите запрос Windows на права администратора.

После удаления папка программы будет удалена из:

```text
C:\Program Files\NetworkMonitor
```

Ярлык из меню Пуск также будет удалён.

## Удаление через команду

Если нужно удалить программу вручную через команду, запустите:

```powershell
"C:\Program Files\NetworkMonitor\NetworkMonitor.exe" --uninstall
```

Команду нужно выполнять с правами администратора. Если прав администратора нет, программа запросит их через стандартное окно Windows.

## Удаление пользовательских данных

Обычное удаление программы не удаляет пользовательские списки IP и сервисов.

Чтобы полностью очистить данные пользователя, удалите папку:

```text
%AppData%\NetworkMonitor
```

Это удалит ручные IP, список серверов и список сервисов.

## Проверка после установки

После установки:

1. Запустите программу через меню Пуск: `Мониторинг сети`.
2. Убедитесь, что открывается главное окно.
3. Нажмите `Сканировать всю сеть`, если нужно выполнить ручной поиск устройств.
4. Перейдите во вкладку `Сервисы` и нажмите `Проверить сервисы`.

Если программа запускается, но не видит часть устройств, проверьте сетевые правила, firewall и доступность ICMP/TCP в локальной сети.

## Частые проблемы

### Установщик не просит права администратора

Проверьте имя файла. В имени должно быть `Setup`, `Install` или `Installer`.

Правильно:

```text
NetworkMonitorSetup-x64.exe
```

Неправильно:

```text
NetworkMonitor.exe
```

### Программа не обновилась

Закройте запущенную программу и повторите установку. Если старый EXE открыт, Windows может заблокировать замену файла.

### Нужно сбросить списки IP и сервисов

Закройте программу и удалите папку:

```text
%AppData%\NetworkMonitor
```

При следующем запуске программа создаст начальные файлы заново.
